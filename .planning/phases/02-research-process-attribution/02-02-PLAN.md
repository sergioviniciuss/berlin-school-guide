<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CI validation → production school data | Invalid dates or incomplete citations must fail `pnpm validate:data` before merge |
| Real-school rules → JSON fixtures | Fixture schools must not be forced to carry production-only date requirements |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-04 | Spoofing | research.lastSourceChecked | mitigate | `validateResearchDates` enforces dates required and `lastSourceChecked >= max(cited dateAccessed)` on all 10 real schools (D-15–D-17) |
| T-02-05 | Tampering | Verified field without citation | mitigate | Existing `schoolSchema.superRefine` + `validateFieldCitations`; audit fixes gaps (D-11, D-13) |
| T-02-06 | Denial of service | Global schema date requirements | mitigate | Real-school-only checks in `validateRealSchools()` — do NOT add required dates to `researchMetadataSchema` globally (breaks fixtures) |
| T-02-07 | Information disclosure | Citation URLs | accept | Public government/school URLs only; `sourceSchema` validates URL format |
</threat_model>

# Phase 15.1 — UI Design Contract

> Visual and interaction contract for five Lichtenberg evidence-backed profiles. This phase authors school records. It does not add profile components, schema, routes, or styling. Generated by gsd-ui-researcher. Verified by gsd-ui-checker.

**Source of truth for chrome:** the approved Phase 15 contract (`.planning/phases/15-profile-ui-tags-narrative/15-UI-SPEC.md`) and the components already rendering it. Where this file and that contract differ, production code wins: `perfilDaEscola` prose does not create a Fontes “Citado em:” line. Only field paths and tag ids do.

No sketch findings exist. No new visual system.

## Color

60 / 30 / 10 split, taken from the live profile. Do not add a private-school color, a religious accent, or a new status color.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFFFFF` (`--background` `0 0% 100%`, `bg-white`) | Page background, profile column, source cards, directory cards |
| Secondary (30%) | Neutral-50 `#FAFAFA`, borders Neutral-200 `#E5E5E5` (`border-neutral-200`) | Coverage callout, directory empty panels, card borders, filter sidebar border |
| Accent (10%) | Blue-700 `#1D4ED8` (`text-blue-700`); chip fill Blue-50 / text Blue-800 | Reserved list below only |
| Destructive | Red-50 / Red-800 | Existing `StatusBadge` for `conflicting` only. These five must not introduce conflicting evidence as a visual treatment. |
| Caution | Amber-50 / Amber-900 | Existing `StatusBadge` for `not_confirmed` (“Informação inferida, não confirmada”). Do not use this status on the five schools’ after-school care, Perfil oficial, or pedagogy. |

Accent reserved for:

1. Text links already in the chrome: methodology, guide links, external source URLs, “Ver fonte”, “Abrir original”, “Ver evidência” / “Ocultar evidência”, “Sugerir correção ou atualização”, “Ver perfil” on the card.
2. Source-type chips (`bg-blue-50 text-blue-800 rounded-full`) for Oficial, Site da escola, Inspeção oficial, Dados públicos, Jornalismo independente, and Fontes comunitárias trianguladas equally.
3. District eyebrow and “Perfil detalhado” / “Perfil básico” badge (`text-blue-700`).
4. Existing focus rings (`focus-visible:ring-primary` / `focus-within:ring-primary`). Primary token stays `221 83% 53%`. Do not retune it.

Not accent: tag label text, confidence badges, Perfil body, section headings, the word “Privada”, factual values. Confidence stays a quiet neutral chip (`bg-neutral-100 text-neutral-800`). `partial` is not amber or red.

Official versus community stays a text label inside expanded evidence (`formatSourceType`). No extra color.

### Authored copy (the only new visible text)

| Rule | Contract |
|------|----------|
| Language | Perfil da escola is Brazilian Portuguese, plain text. `EditorialNarrative` renders `{text}` as a React child. No HTML, Markdown, or MDX. |
| Shape | One short paragraph per school, including schools with zero tags. |
| Voice | Name what the sources confirm. Name decision-relevant points that remain unconfirmed. No ranking, superlatives, or “better than” language. |
| Unconfirmed | Use the stock sentence already on the thin pilots: “Até o momento, não houve confirmação independente…”. It means the sources checked do not say so. It does not mean the school lacks that thing. |
| Evangelical | When a source states the school is evangelical or church-run, the profile field Perfil oficial states that fact and the Perfil repeats it in Brazilian Portuguese. No religious chip. |
| Fees or admission | At most one cited sentence inside the Perfil when a source states it. No new field label. |
| School names | Official names stay as stored (German), matching the current ten. Do not translate the H1. |
| Withhold notes | `qualitativeResearchNotes` never render. Failed community venues do not appear in the Perfil or in Fontes. |
| Missing-field notes | A Portuguese `evidence.note` may be stored on a missing field so the citation exists. `ProfileFieldRow` shows that note only for `not_confirmed` and `conflicting`. Do not change the row to reveal missing notes. |

## What the five profiles show

Routes come from the existing static params. Slugs, unless the official portrait name forces a different stable form:

| School | Path |
|--------|------|
| Grundschule am Neuen Tor | `/schools/grundschule-am-neuen-tor/` |
| Robinson-Schule | `/schools/robinson-schule/` |
| Schule auf dem Lichtenberg | `/schools/schule-auf-dem-lichtenberg/` |
| Schlaufuchs-Schule | `/schools/schlaufuchs-schule/` |
| Evangelische Schule Lichtenberg | `/schools/evangelische-schule-lichtenberg/` |

Each finished portrait-plus-website record uses `coverageLevel: "detailed"`, so the header badge and the directory card badge read **Perfil detalhado**, not Perfil básico.

### Profile composition (existing order)

1. Header: `{district} · {neighbourhood}` eyebrow, H1 name, badge, “Site da escola” when the website is verified, address, compare action, coverage callout, research dates.
2. **Perfil da escola** — required on all five, so this block is present even with zero tags.
3. **Características da escola** — only when that school has at least one tag. Zero tags omits the section. Do not render an empty heading.
4. Factual sections. A missing important field shows the value fallback **Informação não encontrada** plus the missing badge. It does not show citation links on the row (`ProfileFieldRow` links citations only when status is `verified`).
5. **Fontes** — lists sources cited on important fields and on tags, including sources that were checked and were silent when those ids sit on the missing field’s `evidence.citations`. The Perfil paragraph does not add Fontes entries by itself.
6. Correction link to `/report-correction/?school={slug}`.

`not_applicable` renders **Não se aplica** and is only for a field that does not apply (Evangelische Schule Lichtenberg, judged from the portrait). A field that applies and was not found stays **Informação não encontrada**.

After-school care, Perfil oficial, and pedagogy on these five are either verified from a direct portrait or website statement, missing, or not applicable. They must not show **Informação inferida, não confirmada**.

### Directory behavior that is already implemented

- Cards appear in the existing list. Order of the current ten stays; the five are appended, so Adam-Ries remains first.
- A new neighbourhood string becomes a Bairro checkbox with that string as the label. No new filter UI.
- `pedagogyFocus` becomes a Foco educacional checkbox only when that field is a direct verified value. A missing focus adds no chip.
- Compare still selects the school by slug. The compare table does not gain a tag row.

### Interaction

No new interactions. Tag evidence still toggles with `aria-expanded` and “Ver evidência” / “Ocultar evidência”. Removing tags from a record hides Características and leaves the Perfil and the factual page intact. The correction link stays a native `<a>`.

## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| Component props → rendered DOM | `note`, `children`, `term` props are supplied only from TypeScript call sites (later plans' static demo data / MDX content authored in-repo at build time) — never from runtime user input or query params |
| `BerlinCallout` summary link target | Hardcoded literal string `/guides/berlin-school-system`, not constructed from any variable or user-controlled value |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-01 | Tampering | `BerlinCallout` / `GlossaryTerm` props | accept | Props are TypeScript-typed and only ever supplied by other in-repo static components/constants at build time; there is no runtime data-fetching or user-supplied prop value in this phase |
| T-09-02 | Information Disclosure | `BerlinCallout` summary link | accept | Link target is a hardcoded same-origin static path (`/guides/berlin-school-system`), not derived from any input — no open-redirect or SSRF surface |
| T-09-03 | Elevation of Privilege (XSS via children) | `BerlinCallout`/`GlossaryTerm` `children` | accept | `children` is React `ReactNode` rendered through JSX (auto-escaped) and is only ever authored in-repo `.mdx`/`.tsx` source at build time — no `dangerouslySetInnerHTML`, no runtime string interpolation into markup |

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Static school JSON → profile render | Field values and evidence notes rendered as React text nodes |
| Profile citation links → external URLs | User leaves site via Abrir original links |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering | ProfileFieldRow value display | mitigate | React text escaping only — no dangerouslySetInnerHTML on field values or evidence.note |
| T-04-02 | Spoofing | External citation links | mitigate | rel="noopener noreferrer" on Abrir original; URLs from validated school.sources only |
| T-04-03 | Repudiation | anecdotal_reserved sources | mitigate | formatSourceType returns null; SourcesSection skips unrenderable types |
| T-04-04 | Information Disclosure | getSchoolBySlug | accept | Closed dataset of 10 public schools; undefined for unknown slugs |
</threat_model>

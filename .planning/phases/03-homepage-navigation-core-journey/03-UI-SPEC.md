## 2. Visuals — Layout & Wireframes

### Global page shell

Every route wraps `{children}` between shared chrome in `src/app/layout.tsx`:

```text
┌─────────────────────────────────────────────────────────────┐
│ SiteHeader (sticky top, full width, white bg, bottom border) │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  <main> — page-specific content (existing max-width rules)  │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│ SiteFooter (full width, neutral-50 bg, centered copyright)  │
└─────────────────────────────────────────────────────────────┘
```

**Homepage main:** Remove `min-h-screen flex justify-center` centering. Use top-aligned landing flow: `mx-auto max-w-3xl px-6 py-12 space-y-12`.

**Directory main:** Keep `max-w-7xl px-4 py-8 sm:px-6 lg:px-8`.

**Methodology main:** Keep `max-w-3xl px-6 py-12 space-y-8`.

### SiteHeader — desktop (≥ md, 768px)

```text
┌──────────────────────────────────────────────────────────────┐
│  [Berlin School Guide]          Início  Escolas  Metodologia │
│   (logo link → /)              (horizontal nav, gap-8)      │
└──────────────────────────────────────────────────────────────┘
  ↑ px-6, h-16 (64px), items-center, justify-between
  ↑ border-b border-neutral-200, bg-white, sticky top-0 z-40
```

- Logo: `text-base font-semibold text-neutral-950`, always `<Link href="/">`.
- Nav links: `text-sm font-medium text-neutral-700 hover:text-neutral-950`.
- **Active link:** `font-semibold text-primary` + `border-b-2 border-primary` (underline via bottom border on desktop inline nav).
- Active detection: exact pathname match (`/` only on home; `/schools` prefix not needed yet — no nested school routes in Phase 3).

### SiteHeader — mobile (< md)

```text
┌──────────────────────────────────────┐
│  [Berlin School Guide]        [≡]   │
└──────────────────────────────────────┘
```

- Hamburger: 44×44px touch target, `Button variant="outline"` or ghost icon button with `Menu` icon (lucide, 20px).
- Tapping opens **Sheet** from the right (see mobile menu wireframe).
- Logo remains visible; nav links hidden until sheet opens.

### Mobile menu (Sheet)

```text
                    ┌─────────────────────┐
                    │  Navegação      [X] │
                    ├─────────────────────┤
                    │  Início             │
                    │  Escolas            │
                    │  Metodologia        │
                    └─────────────────────┘
```

- Sheet width: `w-[280px]` or `max-w-[85vw]`.
- Sheet title (sr-only or visible): **Navegação**.
- Nav links: stacked, full-width tap rows, `py-3 px-4 text-base`.
- **Active link:** `font-semibold text-primary bg-neutral-50 border-l-4 border-primary`.
- Close on link click (navigate + sheet closes).
- Focus trap and Escape-to-close via shadcn Sheet defaults.

### Homepage — landing layout

```text
┌─────────────────────────────────────────┐
│  HERO (GuideIntro)                      │
│  eyebrow / h1 / description             │
├─────────────────────────────────────────┤
│  JOURNEY CARDS                          │
│  ┌───────────────────────────────────┐  │
│  │ PRIMARY — Explorar escolas          │  │
│  │ (larger card, left accent border)   │  │
│  │ [Ver escolas em Lichtenberg]        │  │
│  └───────────────────────────────────┘  │
│  ┌───────────────────────────────────┐  │
│  │ SECONDARY — Entender metodologia    │  │
│  │ (smaller/outline card)              │  │
│  │ [Como funciona nossa pesquisa]      │  │
│  └───────────────────────────────────┘  │
├─────────────────────────────────────────┤
│  SCOPE NOTE (Cobertura inicial)         │
│  short paragraph, neutral-600 text      │
└─────────────────────────────────────────┘
```

**Desktop (≥ md):** Journey cards in a 2-column grid — primary card spans visual dominance via `md:col-span-2` stacked layout OR primary on top full-width + secondary below at ~75% width. **Chosen pattern:** stacked vertical (CONTEXT D-03 "stacked on mobile"; on desktop primary card is full-width with larger padding, secondary card below at full width but visually lighter — simpler and matches mobile-first).

**Primary journey card:**
- `rounded-lg border border-neutral-200 bg-white p-6 md:p-8`
- Left accent: `border-l-4 border-l-primary`
- Title: `text-xl font-semibold`
- Body: `text-base leading-8 text-neutral-700 mt-2`
- CTA: `Button asChild` + `Link`, default variant, `mt-4`

**Secondary journey card:**
- `rounded-lg border border-neutral-200 bg-neutral-50 p-5 md:p-6`
- No left accent bar; title `text-xl font-semibold`
- CTA: `Button asChild variant="outline"` + `Link`

Cards are fully clickable optional enhancement; minimum requirement is visible CTA button/link inside each card.

### SiteFooter

```text
┌──────────────────────────────────────────────────────────────┐
│        © 2026 Berlin School Guide    ·    Metodologia        │
└──────────────────────────────────────────────────────────────┘
  ↑ py-8, text-center, text-sm text-neutral-600, bg-neutral-50
  ↑ border-t border-neutral-200
  ↑ Metodologia link: text-blue-700 underline on hover
```

Single row on desktop; stack copyright above link on very narrow screens if needed (`flex flex-col sm:flex-row gap-2 justify-center items-center`).

### Interaction summary

| Interaction | Behavior |
|-------------|----------|
| Logo click | Navigate to `/` from any page |
| Nav link click | Client navigation; active state updates |
| Mobile hamburger | Opens Sheet; body scroll locked (Sheet default) |
| Journey card CTA | Navigate to `/schools` or `/methodology` |
| Footer methodology link | Navigate to `/methodology` |

### Accessibility checklist (Phase 3 minimum)

- `<header>` landmark with `aria-label="Cabeçalho do site"` or implicit nav labeling.
- `<nav aria-label="Navegação principal">` wraps desktop links and mobile sheet links.
- Skip link: **deferred** — not required Phase 3 unless trivial to add.
- Focus visible on all interactive elements (existing Button ring: `focus-visible:ring-2`).
- Heading order: homepage h1 in hero; journey card titles are h2; scope note is not a heading (use `<p>` with optional `<span class="font-medium">` label).

## 3. Color

Extend existing CSS variables in `globals.css`; do not introduce new hue families in Phase 3.

| Role | Value | Tailwind / CSS | Usage |
|------|-------|----------------|-------|
| Dominant (60%) | `hsl(0 0% 100%)` | `bg-background`, `bg-white` | Page background, header bg, primary card bg |
| Secondary (30%) | `hsl(220 13% 96%)` approx | `bg-neutral-50`, `border-neutral-200`, `text-neutral-700` | Footer bg, secondary card bg, borders, body text |
| Foreground | `hsl(224 71% 4%)` | `text-foreground`, `text-neutral-950` | Headings, logo |
| Accent (10%) | `hsl(221 83% 53%)` | `bg-primary`, `text-primary`, `border-primary` | Primary CTAs, active nav indicator, primary card left border |
| Link accent | `#1d4ed8` approx | `text-blue-700` | Eyebrows, inline links, footer link — matches existing GuideIntro and directory |
| Muted text | neutral-600/700 | `text-neutral-600`, `text-neutral-700` | Descriptions, copyright, scope note |
| Destructive | — | — | Not used in Phase 3 |

**Accent reserved for (explicit list):**
- Primary Button background (`bg-primary`)
- Active navigation indicator (border/text)
- Primary journey card left accent bar
- Inline text links (`text-blue-700`) — eyebrows, methodology links, footer link

**Not accent:** Logo text (neutral-950), inactive nav (neutral-700), secondary card (neutral surfaces only), hamburger icon (neutral-900).

**Contrast:** Primary button white-on-blue meets WCAG AA for normal text at 14px+.

## 4. Typography

Match `GuideIntro` and existing page patterns. Exactly **4 sizes**, **2 weights**.

| Role | Size | Weight | Line height | Tailwind | Usage |
|------|------|--------|-------------|----------|-------|
| Body | 16px | 400 (regular) | 1.5 (24px) | `text-base leading-6` | Footer, nav links, scope note body |
| Label | 14px | 600 (semibold) | 1.4 (20px) | `text-sm font-semibold` | Eyebrow, nav labels, copyright |
| Heading | 20px | 600 (semibold) | 1.2 (24px) | `text-xl font-semibold` | Journey card titles (primary and secondary) |
| Display | 36px | 600 (semibold) | 1.2 (44px) | `text-4xl font-semibold` | Page h1 (hero) |

**Extended usage (same tokens only — no 5th size):**
- Hero description: `text-base leading-8` (Body token, relaxed line height for hero).
- Secondary card title: `text-xl font-semibold` (Heading token).
- Logo: `text-base font-semibold` (Body size + semibold weight).

**Font family:** `Arial, Helvetica, sans-serif` on `body` — no change Phase 3.

**Letterspacing:** Eyebrow keeps `uppercase tracking-wide` from GuideIntro.

## 5. Spacing

4px base scale. Use Tailwind spacing scale aligned to multiples of 4.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | `p-1`, icon internal padding |
| sm | 8px | `gap-2`, compact inline gaps |
| md | 16px | `p-4`, `gap-4`, mobile page horizontal padding base |
| lg | 24px | `p-6`, `gap-6`, `px-6` page padding, card padding mobile |
| xl | 32px | `p-8`, `gap-8`, section gaps on homepage, directory sidebar sticky offset |
| 2xl | 48px | `py-12` homepage/methodology vertical padding |
| 3xl | 64px | `h-16` header height |

**Page padding contract:**

| Page type | Horizontal | Vertical |
|-----------|------------|----------|
| Home, methodology | `px-6` | `py-12` |
| Schools directory | `px-4 sm:px-6 lg:px-8` | `py-8` |
| Header | `px-6` | `h-16` (implicit py via flex center) |
| Footer | `px-6` | `py-8` |

**Section gaps (homepage):** `space-y-12` between hero, journey cards block, and scope note.

**Journey cards gap:** `space-y-4` between primary and secondary cards.

**Touch targets:** Hamburger and mobile nav rows minimum **44px** height.

**Exceptions:** None beyond 44px touch targets for mobile menu controls.

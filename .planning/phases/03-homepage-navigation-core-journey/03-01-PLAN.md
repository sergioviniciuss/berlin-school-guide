<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Static JSX → browser | Nav labels and hrefs are hardcoded constants — no user input |
| Client header → routes | Links use internal paths only from `NAV_ITEMS` constant |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Spoofing | SiteHeader nav hrefs | mitigate | `NAV_ITEMS` constant with typed `as const` paths — no dynamic href from query/params |
| T-03-02 | Tampering | Nav labels via XSS | accept | Static JSX only — no `dangerouslySetInnerHTML` in nav components |
| T-03-03 | Denial of Service | Mobile menu focus trap | mitigate | Use shadcn Sheet defaults (focus trap, Escape-to-close) per D-10 |
| T-03-04 | Information Disclosure | Footer/header | accept | Public static content only; no secrets |
</threat_model>

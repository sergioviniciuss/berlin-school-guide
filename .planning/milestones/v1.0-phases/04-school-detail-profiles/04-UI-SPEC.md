# Phase 4 — UI Design Contract

> Visual and interaction contract for School Detail Profiles. Generated by gsd-ui-researcher from locked CONTEXT.md decisions (D-01 through D-23).

**Scope:** Static school detail pages at `/schools/[slug]` for all 10 Lichtenberg schools, per-field evidence badges, consolidated Fontes section, directory card links, three-school detailed tier upgrade, SiteHeader `/schools/*` active state, 404 for unknown slugs. No Open Day questions, directory UX polish, or comparison.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn/ui (partial — Button, Sheet from Phase 3) |
| Preset | new-york, baseColor neutral, cssVariables true (`components.json`) |
| Component library | Radix Slot (Button), Radix Dialog (Sheet) |
| Icon library | lucide-react — use `ExternalLink`, `ChevronRight` on profile cards only |

No third-party registries.

## 1. Copywriting Contract

All user-facing copy in Brazilian Portuguese. Tone: practical, neutral, trust-focused per `docs/EDITORIAL_GUIDE.md`. Never imply school quality from coverage or evidence status.

| Description (meta) | `Perfil de {school.name.value} em {district ou "Berlim"} com status de evidência em cada informação — o que confirmamos, o que falta e de onde veio.` |

Use verified `name`, `location.district` values when available; fall back to neutral phrasing when district is missing.

| Interaction | Behavior |
|-------------|----------|
| Directory card click | Navigate to `/schools/[slug]` |
| `Ver fonte` on field | Scroll/focus to `#source-{id}` in Fontes |
| `Abrir original` | Open source URL in new tab |

### Accessibility checklist (Phase 4 minimum)

- Profile h1 is school name; section titles are h2; field labels are `<dt>`.
- Every field row exposes status badge text to screen readers (visible badge, not icon-only).
- External links: visible text + `rel="noopener noreferrer"`; append sr-only `(abre em nova aba)` if icon-only variant used anywhere.
- Fontes anchor targets: `id` attributes stable and unique per page.
- Clickable directory cards: single link wraps card; no nested interactive elements.
- Focus order follows visual order in single-scroll layout.
- Color is not sole indicator of status — badge always includes text label from `formatFieldStatus`.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Checkbox toggle → URL update | Client-only state; slugs must exist in directory dataset |
| Compare CTA href | Must not accept external URLs |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-05 | Tampering | compare param in URL | mitigate | parseCompareSlugs caps at 4; only known slugs toggleable from UI |
| T-06-06 | Spoofing | CompareBar CTA | mitigate | Use buildComparePageHref — hardcoded `/compare` path only |
| T-06-07 | Tampering | Filter param drop on compare toggle | mitigate | Extend toQueryString(filters, sortKey, compareSlugs?) preserving all filter keys (RESEARCH Pitfall 2) |
</threat_model>

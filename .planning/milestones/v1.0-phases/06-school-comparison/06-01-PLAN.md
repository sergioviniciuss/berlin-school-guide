<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL query params → slug list | Untrusted share links parsed into internal slug allowlist lookup |
| Parsed slugs → rendered DOM | Only resolved School records render values — never raw slug strings as facts |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Tampering | `parseCompareSlugs` | mitigate | Trim, dedupe, cap at 4 slugs; ignore empty segments (D-02) |
| T-06-02 | Spoofing | `buildComparePageHref` | mitigate | Hardcode `/compare` path prefix; slugs joined from internal selection only |
| T-06-03 | Denial of Service | Huge comma-separated slug strings | mitigate | Cap at 4 on parse; loop breaks early |
| T-06-04 | Tampering | Unknown slug in URL | mitigate | `resolveCompareSchools` skips unknown slugs; surfaces notice downstream (D-18) |
</threat_model>

# Plan 08-01: CI Playwright Gates

<objective>
Wire Playwright smoke tests into CI for every PR to main (with docs-only path filters) and add a fuller multi-browser job on main pushes — serving the static export reliably.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CI runners | Trusted GitHub Actions environment; no production secrets needed for static site |

## Threats

| Threat | Severity | Mitigation |
|--------|----------|------------|
| Flaky e2e blocking merges | medium | Serve static `out/`; single worker in CI; retry policy optional |
| Path filters skip needed e2e | medium | Never ignore src/, e2e/, .github/, package.json |

No auth or PII in e2e.
</threat_model>

<tasks>

<task type="auto">
  <name>Task 1: CI static server config</name>
  <action>
    - Add `playwright.ci.config.ts` extending base config with webServer:
      - `command`: serve `out/` on port 4310 (add `serve` devDependency or use `npx serve`)
      - `url`: http://127.0.0.1:4310
    - Add npm script `e2e:ci` using CI config
    - Document that CI runs build before e2e
  </action>
</task>

<task type="auto">
  <name>Task 2: PR smoke e2e job</name>
  <action>
    - Extend `.github/workflows/ci.yml` with `e2e-smoke` job (or add steps to validate job after build):
      - `pnpm exec playwright install chromium --with-deps`
      - `pnpm build` (if not shared artifact from validate job)
      - `pnpm e2e:ci -- e2e/smoke.spec.ts`
    - Add `pull_request` path filters: skip job when ONLY docs/.planning/README/root md change
    - Keep existing lint/typecheck/test/validate:data/build required
  </action>
</task>

<task type="auto">
  <name>Task 3: Main fuller e2e workflow</name>
  <action>
    - Create `.github/workflows/e2e-full.yml` triggered on push to `main`:
      - Run smoke + new fuller specs (placeholder for 08-03 a11y.spec.ts)
      - Browser matrix: chromium, firefox, webkit
      - Same build + serve pattern
  </action>
</task>

</tasks>

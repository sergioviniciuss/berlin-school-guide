<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL query params → client filter state | Untrusted share links parsed into typed filter/sort state |
| Search query → rendered UI | User-supplied `q` displayed in chips and empty states |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Tampering | `sortFromSearchParams` | mitigate | Whitelist `name\|coverage\|tier`; unknown values fall back to `name` (D-05) |
| T-05-02 | Tampering | `?q=` displayed in UI | mitigate | React text nodes only — no dangerouslySetInnerHTML on search query |
| T-05-03 | Spoofing | `router.replace` | accept | Only `${pathname}${toQueryString(...)}` — no external URLs [existing pattern] |
| T-05-04 | Denial of Service | Client filter on large arrays | accept | N=10 trivial; memoization documented in plan 05-03 (DISC-07) |
</threat_model>

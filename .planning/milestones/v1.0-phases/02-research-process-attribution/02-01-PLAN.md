    Extend `docs/research/SCHOOL_RESEARCH_WORKFLOW.md` with:

    1. **Per-field decision trees** (explicit numbered steps per D-04). Include at minimum:
       - **ganztag** (directory tier): portrait lists model → `verified`; no portrait → `missing`
       - **afterSchoolCare**: independent Ganztag/Hort source → `verified`; infer from ganztag → `not_confirmed` via `inferredFrom()` + mandatory Portuguese note; no data → `missing`
       - **schoolProfile / pedagogyFocus**: infer from offers → `not_confirmed` via `inferredFrom()`; never `verified` from offers alone
       - **bilingualPrograms / internationalPrograms**: default `missing` unless explicitly verified
       - **inspectionAvailability** (directory-only): default `missing`, not portrait `not_confirmed`
       - **Evidence status assignment** section listing all statuses and when to use each

    2. **Inference rules** — document `inferredFrom()` pattern: always `not_confirmed`, never `verified`; cite source field; mandatory Portuguese note.

    3. **Citation rules** — verified fields require ≥1 citation to acceptable primary/secondary source with complete `sourceSchema` metadata (publisher, url, dateAccessed). Reference `pnpm validate:data` enforcement (D-13 already in schema).

    4. **Coverage v2 reference** — directory tier = 11 portrait fields ("Pesquisa básica"); detailed = 23 fields ("Pesquisa detalhada"); numerator counts only `verified` fields. Link to `getCoverageTierLabel` vocabulary.

    5. **Date update rules** (D-14, D-15, D-16, D-18):
       - Set `dateAccessed` on each source individually when checked
       - `lastSourceChecked` = date of most recently accessed cited source
       - `lastResearched` = date of last full field-by-field review
       - Re-research step: whenever any field or source is re-checked, update BOTH dates

    6. **Completion gate** — final step: run `pnpm validate:data`; fix all failures before marking research complete (D-05).
